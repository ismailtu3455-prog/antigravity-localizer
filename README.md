> **Полноценный многоязычный локализатор для Antigravity 2.0 с переключением языков прямо в интерфейсе приложения!**

---

## ✨ Возможности

- 🚀 **Установка в 1 команду**: Запустите одну строчку в PowerShell или используйте готовый `.exe`.
- 🔄 **Мгновенное переключение на лету**: Переключайтесь между языками в любой момент без перезапуска приложения.
- 🏳️ **Аккуратная кнопка с флагом**: Размещена прямо в верхнем баре навигации рядом со стрелками `[<-]` `[->]`.
- 🌍 **Выпадающее меню стран**: Нажмите на флаг, чтобы открыть стильное меню со списком доступных языков.
- ⌨️ **Быстрая клавиша `Alt + L`**: Мгновенно переключайте языки с клавиатуры (работает и в русской, и в английской раскладке).
- 🛡️ **Защита от сброса**: Отключена автоперезапись файлов при выходе и перезапуске, выбор языка навсегда сохраняется на диске.

## ⚡ Быстрая установка

### Вариант 1: Установка в 1 команду через PowerShell (Рекомендуется)

Откройте PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/<ВАШ_АККАУНТ>/antigravity-localizer/main/install-standalone.ps1 | iex
```

*(Скрипт полностью автономен, сам сделает бэкап, очистит кеш апдейтера и перезапустит Antigravity с флагом в верхнем баре).*

---

### Вариант 2: Автономный EXE-файл (в 1 клик, без интернета)

1. Скачайте файл **[`AntigravityLocalizerSetup.exe`](AntigravityLocalizerSetup.exe)** (3.6 МБ).
2. Запустите его двойным кликом.
3. Готово! Всё необходимое уже зашито внутри `.exe`.

---

## 🛠️ Сборка из исходников

Если вы хотите собрать установщик или обновить словари самостоятельно:

```bash
# 1. Установка зависимостей
npm install

# 2. Обновление движка и словарей
node generate-engine.js

# 3. Компиляция автономного EXE-установщика
node build-installer.js

# 4. Генерация автономного скрипта install-standalone.ps1
node generate-standalone-ps1.js
```

---

## ↩️ Как вернуть оригинальный интерфейс (Откат)

- Через PowerShell:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\install-standalone.ps1 -Restore
  ```
- Либо запустите:
  ```cmd
  restore.bat
  ```
