# 🌐 Antigravity Localizer

Многоязычный локализатор для Antigravity с переключением языка прямо внутри интерфейса приложения.

Поддерживает русский, украинский, казахский, белорусский, узбекский и английский языки. Переключение выполняется без переустановки и без ручного редактирования файлов.

## ✨ Возможности

* 🚀 Установка одной командой через PowerShell или через готовый `.exe`.
* 🔄 Переключение языка без перезапуска Antigravity.
* 🌐 Быстрый выбор языка из выпадающего меню в интерфейсе.
* 🏳️ Кнопка выбора языка размещается в верхней панели рядом с навигацией `[←]` `[→]`.
* ⌨️ Горячая клавиша `Alt + L` для быстрого переключения языка.
* 💾 Выбранный язык сохраняется на диске и не сбрасывается после перезапуска.
* 🛡️ Автоматическое создание резервной копии перед изменением файлов.
* 🧹 Очистка кеша обновлений, чтобы изменения локализации не перезаписывались автоматически.
* ↩️ Возможность полностью вернуть оригинальный интерфейс в любой момент.
* ☁️ Встроенная настройка прокси и [иллюстрированная инструкция Cloudflare Worker (со скриншотами)](CLOUDFLARE_GUIDE.md) для обхода региональных ограничений.
* 📊 Встроенное управление и интеграция виджета **Antigravity Tokens HUD** (контекст сессии, лимиты и квоты запросов) прямо во вкладке «Твики».

## ⚡ Установка

### PowerShell

Это рекомендуемый способ установки.

Откройте PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/ismailtu3455-prog/antigravity-localizer/main/install-standalone.ps1 | iex
```

Установщик автоматически:

1. Находит установленный Antigravity.
2. Создаёт резервную копию изменяемых файлов.
3. Устанавливает локализацию.
4. Добавляет переключатель языка в интерфейс.
5. Настраивает сохранение выбранного языка.
6. Очищает кеш обновлений при необходимости.
7. Перезапускает Antigravity.

После установки переключатель языка появится в верхней панели приложения.

---

### 📦 Готовый EXE

Установщик не требует Node.js или ручной настройки проекта.

1. Скачайте [`AntigravityLocalizerSetup.exe`](AntigravityLocalizerSetup.exe).
2. Запустите файл.
3. Следуйте инструкциям установщика.

Размер установщика: около `3.6 МБ`.

## ⌨️ Управление

### Переключение языка

Нажмите:

```text
Alt + L
```

Горячая клавиша работает независимо от текущей раскладки клавиатуры.

### Выбор языка через интерфейс

Нажмите кнопку с флагом в верхней панели Antigravity и выберите нужный язык из списка.

После выбора интерфейс изменится сразу.

---

## ↩️ Откат

Локализатор создаёт резервную копию изменяемых файлов перед установкой.

Чтобы вернуть оригинальный интерфейс Antigravity, используйте один из способов.

### PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install-standalone.ps1 -Restore
```

### BAT-файл

```cmd
restore.bat
```

После восстановления Antigravity вернётся к исходному интерфейсу.

## 🛠️ Сборка из исходников

Для самостоятельной сборки потребуется Node.js и установленный `npm`.

Установите зависимости:

```bash
npm install
```

Сгенерируйте движок локализации и словари:

```bash
node generate-engine.js
```

Соберите автономный EXE-установщик:

```bash
node build-installer.js
```

Сгенерируйте автономный PowerShell-установщик:

```bash
node generate-standalone-ps1.js
```

После этого готовые файлы будут доступны в соответствующих директориях проекта.

## 🔐 Безопасность

Перед изменением файлов локализатор создаёт резервную копию.

При необходимости исходные файлы можно восстановить через встроенный механизм отката.

Локализатор не требует постоянной работы отдельного фонового приложения.

## ❓ Частые вопросы

### Нужен ли Node.js для установки?

Нет.

Node.js требуется только для сборки проекта из исходного кода.

### Нужно ли запускать локализатор после каждого запуска Antigravity?

Нет.

Выбранный язык сохраняется, а необходимые изменения применяются автоматически.

### Можно ли вернуться к английскому интерфейсу?

Да.

Выбери `English` в меню языков.

### Что делать после обновления Antigravity?

Если новая версия перезаписала изменённые файлы, повторно запусти установщик.

---

## 📌 Важно

Локализатор изменяет файлы установленного приложения Antigravity. После крупных обновлений структура файлов приложения может измениться, поэтому совместимость с будущими версиями зависит от изменений самого Antigravity.

Перед использованием рекомендуется сохранить резервную копию важных файлов.
